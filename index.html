About OpenStreetMap Sound Demo (Navara)

This is the Navara port of the OpenStreetMap Sound Demo, which is built on MapLibre GL JS.

Navara does not read the MapLibre Style Spec, so the basemap is not a style document: each OpenMapTiles source layer is styled with Navara's own vector materials, and the buildings are extruded per feature from render_height.

Vector tiles by OpenStreetMap Japan, data © OpenStreetMap contributors.

Original sound example developed by Mapbox, and all music in the original is by Otherman Records.

Original demo developed by Taro Matsuzawa (smellman).

VJ mode is experimental and supports desktop browsers only. It drives the buildings from a live audio input, so route your system output into a virtual input device first, then press Turn On VJ Mode. Press Esc to leave it.
